## Todos os Comandos

| Comando | Permissão | Descrição |
|---------|-----------|-----------|
| `/rpgskills status [player]` | Player | Mostra nível, XP, pontos, buff |
| `/rpgskills set level <1-165>` | Admin | Define nível |
| `/rpgskills set slotchest <50-400>` | Admin | Define slots de baú |
| `/rpgskills set stack <1-1000>` | Admin | Define stack multiplier |
| `/rpgskills set xpbuff <2\|5\|10\|off> [s\|max]` | Admin | Aplica/remove buff XP |
| `/rpgskills maxskills` | Admin | Nível máx + todas classes |
| `/rpgskills reset points` | Player | Respec (custa coins) |
| `/rpgskills reset zero` | Admin | Reset completo |
| `/rpgskills restore inventory` | Player | Restaura backup |
| `/rpgskills restore inventory list` | Player | Lista backups |
| `/rpgskills config reload` | Admin | Recarrega config |
| `/rpgskills help` | Player | Ajuda |
