ClassesClasses

34 classes, 5 pontos em cada34 classes, 5 points each

Cada nível do personagem dá 1 ponto. Coloque na classe que quiser: os bônus somam a cada ponto e cada nível da classe pode liberar uma habilidade nova. Clique numa classe para ver tudo, nível por nível. Each character level gives 1 point. Put it into any class: bonuses add up with every point and each class level can unlock a new ability. Click a class to see everything, level by level.

RegrasRules

Como os pontos funcionamHow points work

Bônus que somamStacking bonuses

O bônus de cada atributo cresce igual a cada ponto: uma classe com +10% por ponto chega a +50% com 5 pontos. Algumas classes funcionam por faixa (comida, poções, máquinas, armadilhas), com um valor fixo para cada nível.Each stat grows the same with every point: a class with +10% per point reaches +50% at 5 points. Some classes work in tiers (food, potions, machines, traps), with a fixed value for each level.

Mudar de ideiaChanging your mind

Na aba Status, "Resetar pontos de classe" devolve todos os pontos sem mexer no nível (custa 1.000 moedas por nível, configurável). "Zerar progressão" recomeça do nível 1. Nenhum dos dois mexe na Loja do mundo.In the Status tab, "Reset class points" gives every point back without touching your level (costs 1,000 coins per level, configurable). "Reset progression" starts over from level 1. Neither touches the world Shop.

Ligue só o que quiserTurn on only what you want

Cada classe pode ser desligada no RPG Skills Config. Quando todas as classes ativas chegam ao nível 5, você ganha a passiva Mestre das Classes: partículas brancas e um rastro ao caminhar.Each class can be turned off in RPG Skills Config. When every active class reaches level 5, you get the Master of Classes passive: white particles and a trail as you walk.
