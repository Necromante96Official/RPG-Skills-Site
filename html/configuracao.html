💻 Comandos

// Jogador
/rpgskills status // nível, XP, pontos, buff
/rpgskills reset points // respec (custa coins)
/rpgskills restore inventory // restaurar backup
/rpgskills restore inventory list // listar backups
/rpgskills help // ajuda
// Admin (MP)
/rpgskills set level <1-165>
/rpgskills teste level — fireworks de teste (admin)
/rpgskills set slotchest <50-400>
/rpgskills set stack <1-1000>
/rpgskills set xpbuff <2|5|10|off>
/rpgskills maxskills
/rpgskills reset zero
/rpgskills config reload
