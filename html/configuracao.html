RPG Skills Config

Tudo num painel sóEverything in one panel

No menu principal do Necesse, clique em RPG SKILLS CONFIG. As opções ficam em abas, cada campo mostra o valor padrão e a faixa permitida, o que foi mudado fica destacado e dá para voltar ao padrão com um clique (por campo ou pela aba inteira). Depois de salvar, reinicie o jogo.In Necesse's main menu, click RPG SKILLS CONFIG. Options are split into tabs, each field shows its default and allowed range, changed values are highlighted and you can go back to default in one click (per field or for the whole tab). After saving, restart the game.

No servidor, vale a configuração do servidor. Ao entrar, o RPG Skills aplica as regras de XP, classes, preços e opções do servidor sem mexer no seu arquivo; ao sair, as suas voltam. Fogos, botão do inventário e linha de status seguem as suas preferências.On servers, the server's config wins. When you join, RPG Skills applies the server's XP, class, price and option rules without touching your file; when you leave, yours come back. Fireworks, the inventory button and the status line follow your own settings.

ComandosCommands

/rpgskills

Digite no chat. Comandos de admin só funcionam para o dono do mundo e administradores do servidor. /rpgskills help lista todos.Type them in chat. Admin commands only work for the world owner and server admins. /rpgskills help lists them all.

/rpgskills status

Mostra nível, XP, pontos livres e bônus de XP.Shows level, XP, free points and XP buff.

jogadorplayer
/rpgskills reset points

Devolve os pontos de classe (custa moedas).Gives class points back (costs coins).

jogadorplayer
/rpgskills restore inventory [list]

Restaura o inventário do backup mais recente, ou lista os backups.Restores your inventory from the latest backup, or lists backups.

jogadorplayer
/rpgskills help

Mostra a ajuda.Shows help.

jogadorplayer
/rpgskills set level <1-170>

Define o nível e zera o XP.Sets the level and clears XP.

admin
/rpgskills set slotchest <50-400>

Define os slots dos baús do mundo, de 10 em 10.Sets the world's chest slots, in steps of 10.

admin
/rpgskills set stack <1-1000>

Define o stack do mundo.Sets the world stack.

admin
/rpgskills set xpbuff <2|5|10|off> [segundos|max]

Aplica ou remove um bônus de XP.Applies or removes an XP buff.

admin
/rpgskills maxskills

Nível máximo e todas as classes ativas no máximo.Max level and every active class maxed.

admin
/rpgskills reset zero

Zera toda a progressão e devolve as moedas de maestria.Resets all progression and refunds mastery coins.

Define as vitórias contra um monstro no Grimório (ou setlevel <slot> <nível> para um lacaio).Sets the wins against a monster in the Grimoire (or setlevel <slot> <level> for a minion).
