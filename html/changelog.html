Changelog Detalhado

Todas as versões desde o lançamento com detalhes completos de cada atualização.

v2.7 CORREÇÃO
  • Config: bonus de slots de trinket corrigido (até 255); desabilita Relic Master quando ativo
  • Config: opção de excluir Incursion Tablets do Loot Master (off por padrão)
  • Config: reset automático de classes em updates (pontos voltam grátis; nível/XP/mastery preservados)
  • Texto de bônus de classe duplicado na UI corrigido
  • Relic Master: itens de terceiros para slots de trinket agora funcionam
  • Loot Master: móveis/máquinas colocados não são multiplicados ao destruir
  • Gold Strike respeita Coin Pouch
  • World stack e chest upgrades salvam imediatamente
  • Performance: colonos e bônus de classe param de recalcular a cada tick
v2.6 NOVIDADE
  • Auto Weapon Select: seleciona arma correta automaticamente (melee/ranged/magic/summon)
  • Accelerated Sleep: dormir entre 8PM-3AM avança a noite instantaneamente
  • Loot Master: forja/forno agora usa o dono do assentamento corretamente
  • Config do Safe Haven não é mais sobrescrita pelo RPG Skills
v2.5 PRINCIPAL
  • 33 classes (era 27): Gourmet, Alquimia, Rancho, Máquinas, Natureza, Armadilhas
  • Menu de Configuração completo com botão no menu principal
  • Angler's Reflex: pesca AFK automática (Sea Master 1)
  • Spoil 1 por ciclo (não a stack inteira), toggleável
  • Compatível com Necesse 1.3.2 e Safe Haven QOL 3.5
  • Comando /rpgskills config reload
  • Passivas individualmente toggleáveis no config
  • Economia ajustável (custo, duração de buff, rate de assentamento)
v2.4 ATUALIZAÇÃO
  • XP de trabalho de colonos compartilhável com equipe
  • Arquivo de config unificado (progressão, classes, stacks, QoL, backup, UI)
  • Gateway Tablets de níveis/biomas diferentes não se mesclam mais
  • Loot Master: dinamite/bombas não multiplicam drops repetidamente
v2.3 NOVIDADE
  • Backup automático: 5 cópias a cada 10 minutos enquanto online
  • Comando /rpgskills restore inventory
  • Redesign da aba Classes: lista à esquerda + painel de detalhes à direita
  • Aba Status dividida: Manual Mágico + Grimório Proibido
  • Controller: LB/RB para trocar abas, D-pad para navegar
  • Janela fecha com ESC automaticamente
v2.0 PRINCIPAL
  • Realm Master nível 5: Sem Rival + 3x XP de assentamento
  • Colonos "Ricos" (6+ personalidades): +1.5x XP extra
  • Leadership Aura: +15% stats nos colonos (22.5% com personalidade alinhada)
  • Zona XP: Charred Forest e Scrapyard separados
  • Recreação: colonos olhando, conversando, etc. dão 5 XP (cap 30/dia)
  • Life Partner: bônus de XP em grupo (off por padrão)
  • Novas passivas: Settlement Leader, Rich Administration, Incursion Specialist
v1.9.2 ATUALIZAÇÃO
  • Arquivo de config de progressão: multiplicador, curva, penalidade
  • Config de classes: ativar/desativar individualmente
  • Master of Classes conta apenas classes habilitadas
  • Estabilidade massiva: save/load, multiplayer sync, segurança de rede
v1.7 ATUALIZAÇÃO
  • Partículas de debuff coloridas (fogo laranja, veneno verde, gelo azul, pesadelo roxo, sangue vermelho)
  • DoT mostra números azuis combinados
  • Debuffs de classe funcionam em bonecos de treino
  • Lifesteal/heal mostra texto flutuante verde
v1.5 ATUALIZAÇÃO
  • Restauração de slots de trinket em reset/respec
  • Barra de XP movível e posição salva
  • Buffs de XP na loja duram 10 minutos
  • Toggle de penalidade de morte no config
v1.2 NOVIDADE
  • 3 novas classes: Gourmet, Alquimia, Rancho
  • Leadership Aura: Realm Master nível 5 dá bônus aos colonos
  • Nível máx aumentado para 150
  • Gold Strike funciona do nível 1
v1.0 LANÇAMENTO
  • Lançamento oficial: 27 classes, sistema RPG completo
  • Shop: buffs XP, world stack, chest slots, Explosive Miner
  • UI de 3 abas: Status, Classes, Loja
  • Hotkey K + suporte a controle
  • Comandos: set level, maxskills, reset points, reset zero
