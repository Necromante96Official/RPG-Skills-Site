[h1]🌟 Update 1.1 - RPG Skills 🌟[/h1]

[h2]Summary[/h2]
[list]
[*] [b]Progression:[/b] leveling now asks for more XP. Level 1 needs 10,000 XP, level 2 needs 20,000 XP, and so on.
[*] [b]Max level:[/b] to go from level 134 to level 135, the player needs 1,350,000 XP.
[*] [b]Point reset:[/b] fixed an issue where coins could be consumed even when the player did not have enough coins to reset. The cost is now simple: 1,000 coins per player level.
[*] [b]Shop:[/b] purchases that use both coins and items are safer. If an item is missing at the final step, coins should not disappear by mistake.
[*] [b]Performance:[/b] the mod does less repeated work while playing, helping reduce stutters and lag without changing class rules.
[/list]

[h2]What changes for players[/h2]
[list]
[*] The road to max level is longer and steadier.
[*] Resetting points still charges coins when there is a cost: a level 25 character pays 25,000 coins, for example. The charge only happens when it can be completed correctly.
[*] Commands and menu buttons follow the same coin safety rules.
[*] Old worlds and characters keep working.
[/list]
